# aiiiii-creator.github.io

这是一个基于 GitHub Pages 官方 `minima` 主题搭建的个人主页。

## 当前发布地址

当前仓库已经是用户主页仓库 `aiiiii-creator/aiiiii-creator.github.io`，默认发布地址是：

`https://aiiiii-creator.github.io/`

## 文件说明

- `_config.yml`: GitHub Pages 和 Jekyll 配置
- `index.md`: 首页
- `about.md`: 关于页
- `projects.md`: 项目页
- `publications.md`: 论文页
- `assets/main.scss`: 自定义样式
- `.github/workflows/pages.yml`: 自动部署工作流

## 发布方法

1. 把 `main` 分支推送到 GitHub。
2. 进入仓库设置里的 **Pages**。
3. 如果还没启用，把 **Source** 设为 **GitHub Actions**。
4. 等待 `Deploy GitHub Pages` 工作流完成。
